## Merchant 面板 Tab 选中态 Sprite 切换（ChantBtn / LotteryBtn）
- 需求：Main 场景 MerchantPanel/Bg/ChantBtn 与 LotteryBtn，选中显示 `Resources/Main/Merchant/图层 72.png`、未选中显示 `图层 73.png`。
- 实现方式：修改 `Assets/Scripts/Merchant/MainMerchantController.cs`（非新增脚本）。
  - 加常量 `SelectedTabSpritePath="Main/Merchant/图层 72"`、`UnselectedTabSpritePath="Main/Merchant/图层 73"`。
  - 加字段 chantTabImage/lotteryTabImage/selectedTabSprite/unselectedTabSprite。
  - Awake 中经静态方法 `ResolveTabImage(Button)` 解析按钮显示用 Image（优先 targetGraphic → GetComponent<Image> → 子节点 "Image"），并 `Resources.Load<Sprite>`。
  - 两个按钮 `transition = Selectable.Transition.None`（纯 sprite 高亮，禁用 ColorTint）。
  - Tab 切换唯一入口 `ShowTab(MerchantTab)` 末尾调用新方法 `ApplyTabVisual(showChant)` 互换两个按钮 sprite。
  - 校验链加入 chantTabImage/lotteryTabImage/sprite 非空检查。
- 关键：Awake 与 Start 均已调用 `ShowTab(MerchantTab.Chant)`，故默认打开面板即为 ChantBtn 选中态，无需额外初始化。

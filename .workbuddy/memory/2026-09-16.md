## 16:23 修复 `Library\Bee\Android` 权限（Explorer 报"你需要来自 Administrators 的权限"）
- **现象**：用户在资源管理器里动一个叫 `Android` 的文件夹，弹 UAC 权限框（重试/取消）。
- **定位手法（可复用）**：对话框里的"**创建日期**"是精确定位线索 —— 2026/8/28 **17:48:02** 唯一命中 `D:\Codex project\Dragon\Library\Bee\Android`（`Assets\Plugins\Android` 是 17:16，`Builds\Android` 是 9/15，都不符）。

- **根因**：该目录**继承被切断**（全部 ACE 无 `(I)`），且真正作用于目录本身的只有 `BUILTIN\Administrators:(F)` 与 `NT AUTHORITY\SYSTEM:(F)`；另两条 `SC-202606051343\Administrator:(OI)(CI)(F)` / `BUILTIN\Administrators:(OI)(CI)(F)` 带 OI+CI，**只作用于子对象不作用于自身**。非提权 Explorer 里 Administrators 是 deny-only → 无 DELETE/写权限。
- **旁证**：`Library` 下其余 13 个顶层目录（APIUpdater/Artifacts/Bee/PackageCache/…）全是 11/11 正常继承，只有 `Bee\Android` 异常 → 是 Android 构建（很可能以提权令牌跑的 Gradle）留下的。
- **修复（已执行）**：`icacls "D:\Codex project\Dragon\Library\Bee\Android" /reset /T /C /Q` → **6856 个文件全部恢复继承，0 失败**，ACE 现与父级 `Library\Bee` 及兄弟目录完全一致。沙箱进程为 **High Mandatory Level**，可直接做 icacls/takeown。
- **全项目复查**：`Assets/Builds/Packages/ProjectSettings/tools/Docs` **无继承被切断**的目录。这几个目录有**额外显式** ACE（`Assets\Scripts`、`Assets\Scripts\{Gold,Merchant,Rune,Share}`、`Assets\Scripts\Ads\*`、`Assets\DragonBound\UI\Variants\V1\Content\Resources\prefabs`、`ProjectSettings`）：`S-1-5-21-*` 各不相同的 SID、`SC-202606051343\CodexSandboxUsers` 的 `(OI)(CI)(M)` —— 是 **Codex/WorkBuddy 沙箱会话每次写入时添加的**，**继承仍在（11 条），只增不减，无害**。

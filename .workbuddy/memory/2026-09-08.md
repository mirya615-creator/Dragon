**关键产出**:`Docs/ForgekeepersGift_具体实现.md`(13 节 + 速查表)

**几个核心事实**(代码层面已确认):

1. **双 ID**:`ITEM_FORGEKEEPERS_GIFT` 是 V1 运行时 ID(`ItemDefinitions.cs:70` + `ItemIdentityContracts.cs:60`);
   `ITEM_FORGEGIFTERS_GIFT`(拼写错)是商店/旧版 ID(`MerchantItemCatalog.cs:25/50/74`),通过
   `DevelopmentItemRunSnapshotProvider.cs:16` 的 `LegacyToRuntime` 字典自动兼容

2. **效果核心**(`ItemEconomyFlowEffects.cs:64-109`):
   - 常量 `FirstForgePickSeconds=90f` / `RepeatForgePickSeconds=90f`
   - `OnRunStart` 重置 `nextDueSeconds=90f` + `stoppedForNoLockedCell=false`
   - `Tick` 每帧 `while (target + 0.0001f >= nextDueSeconds)` 累积循环,
     调 `context.ForgePick.TryGrantForgePick(requiresAdvertisement: true)`
   - **永久停止条件**:`result.Kind == NoLockedCell` → `stoppedForNoLockedCell=true`,`OnRunStart` 才重置
   - `TryActivate` 恒返回 `PassiveOnly`,玩家不能主动触发

3. **接口契约**(`ItemRuntime.cs:248-273`):
   - `IItemForgePickPort.TryGrantForgePick(bool requiresAdvertisement)`
   - `ItemForgePickResultKind`: `Granted` / `NoLockedCell` / `AdvertisementRequired` / `AuthorityUnavailable` / `Rejected`
   - `ItemRunContext.ForgePick`(`ItemRuntime.cs:319`)是唯一消费点

4. **⚠ 关键缺位 — 生产代码未注入 forgePick**:
   - `TwentyWavePressureRuntime.cs:626-645` 的 `new ItemRunRuntime(...)` 没传 `forgePick:` 参数,默认 `null`
   - 运行时 `Tick` 在 `context.ForgePick == null` 处直接 return,**装备了也不会有任何效果**
   - `IItemForgePickPort` 的唯一实现在测试桩 `ItemEconomyFlowEffectsTests.cs:109-127`

5. **商店兑换路径(广告)与 Run 中路径(广告)分叉**:
   - 商店:`MainMerchantController.cs:475-503` → placementId `"merchant_rewarded_item"` →
     `rewardedAdService.ShowAsync` → `merchantGateway.ClaimRewardedAdProductAsync`
   - Run 中:`ItemEconomyFlowEffects.cs:90` 仅传 `requiresAdvertisement: true`,无 placementId
   - 两者是否共享广告配额/同 Ledger 待确认(P1)

6. **设计文档已对账**:`Docs/DragonBound/ItemSystemV1FoundationVerified.md:46` 原文已写
   "absent or rejected ports never report a grant" — 与代码完全一致

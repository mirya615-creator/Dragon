### 关键纠正（重要，勿再踩）
- **Unity 的 Java 源码插件正解 = `Xxx.androidlib` + 自带 `build.gradle`**，不是把 `.java` 散放 `Assets/Plugins/Android/`。
  依据：① Unity 官方《Create an Android Library plug-in》给的 `MyFeature.androidlib` + `src/main/java/<pkg>/` 结构，
  并示范 `AndroidJavaClass("com.company.feature.Controller")` 调用；② Unity 官方《Gradle for Android》明确写
  `unityLibrary/src/main/java` — "Unity **only uses this directory to store the UnityPlayerActivity source file**"；
  ③ 本机 `Unity/2022.3.62t14/.../Tools/GradleTemplates/libTemplate.gradle`（Unity 为 .androidlib 自动生成的模板）里
  `manifest.srcFile 'AndroidManifest.xml'`（→ manifest 必须顶层）、`//java.srcDirs = ['src']` 是**注释掉的**
  （→ 实际走 AGP 默认 `src/main/java`）、依赖只有 `fileTree`（→ **必须自带 build.gradle 才能加第三方依赖**）；
  ④ Google AdMob Unity 插件实证：`GoogleMobileAdsPlugin.androidlib/build.gradle`。
- **因此 P0 步骤 1 的 `DragonBoundGoogleAuthDependencies.xml`（EDM 注入）是冗余的** —— EDM 只注入 unityLibrary 模块，
  Gradle `implementation` 不跨模块传递，对 .androidlib 毫无帮助。建议删除，依赖声明收敛到 `androidlib/build.gradle`。
  注意：`settingsTemplate.gradle` 已有 `google()` + `mavenCentral()`（`RepositoriesMode.PREFER_SETTINGS`），所以
  模块自己声明 `implementation 'androidx.credentials:...'` 能被解析。

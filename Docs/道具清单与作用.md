# Dragon 项目 — 道具系统全清单与作用

> **范围**:本项目所有"道具"(Active / Passive Item + Rune + Shovel + Merchant 商品 + 招募相关)。  
> **数据基线**: `ItemDefinitions.cs`(20 项)、`RuneDefinitions.cs`(14 项)、`ShovelRecruitmentConfig`(铲子)、`MerchantItemCatalog`(商店商品)、`RecruitmentService`(招募价格)。  
> **冻结日期**: 2026-09-08;`Items/Runes/Shovel` 三套系统的客户端代码与协议字段均以 V1 锁定。

---

## 2. Active 道具(6 项,可主动触发,带 CD)

> **用法**:装载到 Active 槽,运行期 `ItemRunRuntime.TryUse(itemId[, targetId])` 或 `TryUseAtPoint(itemId, point)` 触发。冷却通过 `ItemCooldownEffectBase`。  
> **价格档**:Rare 40g / Excellent 60g / Epic 80g / Legendary 120g(见 `MerchantItemCatalog.cs:55-77`)。

### 2.1 `ITEM_WYRMFANG_SNARE` — 蛟齿陷阱 / Wyrmfang Snare
- **稀有度 / 类别**: Rare / Active
- **图标**: `ItemUI/1.png`
- **效果**:对一名敌人放置陷阱;**普通怪 = 目标 MaxHP × 40%**;**Boss = `min(120, MaxHP × 5%)`**(`ItemActiveCombatEffects.cs:208-246`)
- **CD**: 45 秒
- **触发模式**: `target_unit`(可指定 ID,默认取己方路线最靠前)
- **拒绝原因**: `Cooldown` / `NoAliveTargets` / `DamageRejected`

### 2.2 `ITEM_WINTERVEIL_RUNE` — 凛冬卷轴 / Winterveil Scroll
- **稀有度 / 类别**: Rare / Active
- **图标**: `ItemUI/2.png`
- **效果**:对己方路线存活全部敌人施加 **10% 移动减速 5 秒**(全场生效,含 Boss)(`ItemRuntime.cs:379-439`)
- **CD**: 30 秒(独立于 `ItemCooldownEffectBase`,自带 `CooldownRemainingSeconds`)
- **触发模式**: `activate`(无目标)
- **拒绝原因**: `Cooldown` / `NoAliveTargets`(无存活敌人)

### 2.3 `ITEM_RUNEBURST_MINE` — 秘法雷鸣爆 / Arcane Thunderburst
- **稀有度 / 类别**: Excellent / Active
- **图标**: `ItemUI/3.png`(MerchantIconKey 字典中对应旧 ID `ITEM_MANABURST_MINE`,`MerchantItemSnapshotFactory.LegacyToRuntime` 映射)
- **效果**:在指定点释放 AoE;**半径 1.25 cell**;**普通怪 = 80 固定伤害**;**Boss = `min(80, MaxHP × 3%)`**(`ItemActiveCombatEffects.cs:248-301`)
- **CD**: 60 秒
- **触发模式**: `target_point`(必须提供激活点)
- **拒绝原因**: `Cooldown` / `InvalidPlacement`(无激活点)/ `NoAliveTargets`(圈内无目标)

### 2.4 `ITEM_FRENZY_RUNE` — 狂战士战鼓 / Berserker War Drum
- **稀有度 / 类别**: Epic / Active
- **图标**: `ItemUI/4.png`
- **效果**:对一个单位施加 **攻速 ×1.4**;**同一单位最多叠加 2 次**(`ItemActiveCombatEffects.cs:303-334`)
- **CD**: 60 秒
- **触发模式**: `target_unit`
- **拒绝原因**: `Cooldown` / `NoAliveTargets` / `MaxActivationsPerUnit`(已叠满 2 次)

### 2.5 `ITEM_RUNE_OF_TEMPERING` — 锻淬之锤 / Tempering Hammer
- **稀有度 / 类别**: Epic / Active
- **图标**: `ItemUI/5.png`
- **效果**:对一个单位 **50% 升 1 级 / 50% 降 1 级**(夹断在 [1, MaxLevel]);Hero 走 typed next-level 进度时按基础规则 +1/-1(`ItemActiveCombatEffects.cs:336-365`)
- **CD**: 45 秒
- **随机源**: `new RunRandom(context.RunSeed).NextUnit("ITEM_RUNE_OF_TEMPERING.<ordinal>") < 0.5`
- **拒绝原因**: `Cooldown` / `NoAliveTargets` / Progression 失败

### 2.6 `ITEM_WARFORGE_SIGIL` — 战锻徽印 / Warforge Sigil
- **稀有度 / 类别**: Legendary / Active
- **图标**: `ItemUI/6.png`
- **效果**:对一个单位 **立即 +1 级**;Hero 走 `TryCompleteNextHeroLevel`(满级则拒绝);Basic 走 `TryAdjustLevel +1`(`ItemActiveCombatEffects.cs:367-397`)
- **CD**: 90 秒(全 Active 中最长)
- **拒绝原因**: `Cooldown` / `NoAliveTargets` / `MaxLevelReached`(Hero)/ `UnitNotFound`

### 4.2 符文掉落规则(`RuneDropRules`,`RuneDrops.cs:40-89`)

- **随机流**: `PlayerRuneReward`(Content Version `RuneContent.V1`,Algorithm Version `RuneDrop.V1`)
- **种子派生**: FNV-1a 哈希: `(hash ^ seed) * 16777619` → `(hash ^ wave) * 16777619` → 串入 ContentVersion + AlgorithmVersion + RandomStream 字符,得 `(int)hash` 作为 `RunRandom` 种子
- **触发资格**: 仅当 wave ≥ 3 才参与掉落
- **按波段的掉率** (`ChanceForWave`):
  - `wave 1-2` → 0%
  - `wave 3-6` → 12%
  - `wave 7-12` → 18%
  - `wave 13-16` → 28%
  - `wave 17+` → 40%
- **稀有度概率**(`RollRarity`):
  - 3-6 波:Common 75% / Excellent 25%
  - 7-12 波:Common 45% / Excellent 30% / Epic 15% / Legendary 10%
  - 13-16 波:Common 30% / Excellent 30% / Epic 25% / Legendary 15%
  - 17+ 波:Common 15% / Excellent 25% / Epic 40% / Legendary 20%
- **完整 vs 碎片**:
  - Common / Excellent → 100% 完整
  - Epic → 25% 完整 + 75% 碎片(3 碎片合成 1 完整)
  - Legendary → 0% 完整,100% 碎片(5 碎片合成 1 完整)
- **每 Run 成功奖励上限**: 4 次(`MaxSuccessfulRewardsPerRun=4`)
- **服务端入口**: `RuneRunRewardService.CompleteWave(wave)` 仅在波**完整结束**(非 leak/异常退出)后调用

### 4.3 Rune 碎片与合成(`RuneInventory.cs`)

- Epic 完整需要 3 碎片,Legendary 完整需要 5 碎片
- `CanCraftRune(runeId)` / `CraftRune(runeId)` 扣碎片 +1 OwnedCount
- 持久化字段:`OwnedCount`、`FragmentCount`(分别独立累计)

## 5. 招募相关道具(Shovel + Recruit Ticket 等价物)

### 5.1 Shovel 招募铲

- **配置 ID**: `ITEM_SHOVEL`(`ShovelRecruitmentConfig.ShovelConfigId`)
- **数据源**: `Assets/DragonBound/Runtime/Recruitment/Runtime/ShovelRecruitment.cs`
- **图标**: `Assets/Resources/ComponentUI/shovel.png`
- **触发流程**: 每次招募批次生成前 `ShovelRecruitmentState.PreviewDecision` 决定是否本批出铲
- **资格条件**: 棋盘必须有 Locked Cell(否则直接 `NoLockedCells` 拒绝)
- **概率(连续未出铲次数 → 本次掉率)**:
  - 0 次未出 → **20%** (`MissZeroChance`)
  - 1 次未出 → **35%** (`MissOneChance`)
  - 2 次未出 → **50%** (`MissTwoChance`)
  - ≥3 次未出 → **100% 保底**(`ConsecutiveEligibleBatchesBeforeGuaranteed=3`)
- **随机源**: `RunRandom` 流 ID `RecruitShovel`,Context `RecruitShovel.v2`
- **使用入口**: `ShovelUnlockService.TryUnlockCell(gridPosition)` 选中一个 Locked Cell 后消耗一把铲子解锁该格
- **运行时状态**: `ConsecutiveEligibleBatchesWithoutShovel`、`GuaranteedShovelCount`、`LongestEligibleNoShovelInterval`(全部可序列化,可持久化)
- **关键不变量**: PreviewDecision 不修改状态(便于交易失败时不消耗 pity 计数)

### 5.2 招募流程与价格公式

- **基础单元池**(`GreyboxRecruitmentCatalog.Create`):
  - `basic.axe_raider`(斧战士)
  - `basic.longbow_hunter`(弓猎手)
  - `basic.spear_raider`(枪战士)
  - `basic.twinaxe_berserker`(双斧狂战士)
- **招募批次权重**(`FiniteComponentRecruitmentConfig`):
  - `PureBasic` 50% / `OneComponent` 20% / `MultiComponent` 20% / `Shovel` 10%
  - 多组件批:2-4 个 + 至少 1 个基础单元
- **招募价格公式**(`RecruitmentPrice.GetCost`): `10 + 2 × (recruitmentNumber − 1)`
  - 第 1 次 = 10 金币,第 2 次 = 12,第 3 次 = 14…(线性递增)
- **保护窗口**: `OpeningProtectedRecruitCount=3`(前 3 次招募有补偿压力)
- **追赶机制**: `BaseExpectedComponentsPerRecruit=0.80`、`CatchupAllowedComponentsPerRecruit=5.00`
- **每批卡片数**: 5 张(`CardsPerRecruitment=5`)
- **金/紫 Hero 配方**: 18 个组件 ID(`ContractHatchling` / `RuneStaff` / `AncestralWarCrown` / `SkyRanger` / `FlameShaman` / `DragonKnight` / `RuneApprentice` / `StoneScholar` / `AstralMage` / `WanderingSwordsman` / `NorthlandScout` / `StormWarrior` / `ShadowWalker` / `RuneDagger` / `DeepseaHarpooner` / `AncientHarpoon` / `ValkyrieAcolyte` / `DragonboneLongbow`),由 `FrozenHeroConfiguration.cs` 提供

### 5.3 "招募券等价物" — Reroll Token / Gold Key

项目**没有独立**的 Recruit Ticket / Gold Key / Reroll Token 类。所有"刷新卡池""重置招募"等行为均由:

- `RecruitDeck.DrawNext` 重新生成 5 张卡
- `RecruitmentService.CanRecruitNext` 检查资源
- `MerchantItemCatalog.PaymentType=RewardedAd` 实现"看广告代替金币"

这三套机制承担等价功能,详见 `MainMerchantController.cs` 的 `OnLotteryDrawClicked` / `OnBuyClicked`。

### 6.2 Merchant 商店 UI 行为(`MainMerchantController.cs`)

- 两个 Tab:**Chant(商品)+ Lottery(抽奖)**,共用 1 个面板容器
- Active 装备上限 = 2,Passive 装备上限 = 6
- 商品格子:`Assets/Resources/prefabs/Item.prefab` + `ItemBg.prefab`
- 抽奖格子:`LotteryItem.prefab`
- 每次 `Populate` 触发 `OnBuyClicked` / `OnLotteryDrawClicked` 走 `IMerchantGateway`(默认 `LocalMerchantGateway`)
- 删除已购 Item:`OnDeleteItemClicked`(不返还金币)
- 监听 `RunsPerOffer=2`(每 2 次对局刷新 1 次商品)、`ProductsPerOffer=3`(每日 3 件)、`ProductsPerLottery=8`(抽奖 8 件)

### 6.3 加载道具初始装备(`GreyboxMerchantLoadoutController.cs`)

- 启动时拉 `Merchant.GetInventoryAsync()` + `Runes.GetProfileAsync()` → `MerchantItemSnapshotFactory.LegacyToRuntime` 字典映射
  - `ITEM_MANABURST_MINE` → RuneburstMine
  - `ITEM_RUNE_TEMPERING` → RuneOfTempering
  - `ITEM_PACT_ENDURANCE` → PactOfEndurance
  - `ITEM_VETERAN_MARK` → VeteransMark
  - `ITEM_QUARTERMASTER_SATCHEL` → QuartermastersSatchel
  - `ITEM_FORGEGIFTERS_GIFT` → ForgekeepersGift
- 输出 `IItemRunSnapshotProvider` → `DragonBoundBootstrap.InitializeWithItemSnapshotProvider`
- 槽位 UI:`Active0..1` + `Passtive0..5`
